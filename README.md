# 🤖 Synergy Web Dev Orientation Experience

An interactive, animated web experience created for the **Synergy Sports Society orientation**.

This project introduces the Web Development domain at Synergy through a futuristic AI-powered opening, immersive animations, interactive visuals, and a showcase of Synergy's digital presence.

## 🎨 Features

- 🤖 Animated AI assistant introduction
- 🎙️ Browser-based voice interaction
- 📝 Word-by-word synchronized speech animation
- ✨ Futuristic animated background
- 🟠 Synergy-inspired orange visual theme
- 🔵 Subtle blue technology accents
- 🌌 Floating particles and animated grids
- 👩 Personal Web Dev Core introduction
- 🏷️ Quirky animated identity tags
- 💻 Synergy website showcase
- 📱 Fully responsive design
- 🔄 Smooth presentation-style scrolling
- 🚀 Public deployment using Vercel
